# html-design-kit — 자기완결 HTML 문서를 조립하는 공용 디자인 킷

토큰·부품 카탈로그·조립기를 이용해, 프로젝트별 선택값에서 오프라인으로 열 수 있는 HTML 문서를 만듭니다. 부품은 자체 제작 또는 재배포가 가능한 출처로 확인된 것만 제공합니다.

## 언제 켜나

**프로젝트별로 확장 가능한 HTML 문서를 공용 부품과 테마로 만들거나 고칠 때** 켭니다.

기존의 기능 골격·역분석·기획서 분석 템플릿만 쓰는 프로젝트라면 켜지 않습니다.

## 켜면 따라오는 것

| | |
|---|---|
| 규칙 | `rules/assembly.md` — 조립 입력, 자기완결 산출물, 공용 부품 편입 기준 |
| 공용 자산 | `parts/` · `tokens/` · `catalog.json` — 안전 출처 또는 자체 제작 부품과 테마 |
| 도구 | `scripts/assemble.py` · `scripts/build.py` · `scripts/lint.py` |
| 프로젝트에 생기는 것 | 없습니다. 페이지별 입력과 산출물은 기존 프로젝트 문서 자리에서 관리합니다 |
| 프로젝트가 정해야 하는 값 | 제목·테마·부품 구성·페이지 고유 콘텐츠·이미지 |

없습니다.
