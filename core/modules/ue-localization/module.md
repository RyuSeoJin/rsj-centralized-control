# ue-localization — 번역을 시트에서 관리하고 UE 표준 번역 파일로 넣습니다

번역 원본을 스프레드시트에 두고, UE 표준 번역 파이프라인(모으기 → `.po` → `.locres`)으로 게임에
넣을 때의 규칙입니다. 코드에서 번역 키를 만드는 법과 시트의 모양, 내보내기 · 가져오기 순서를 정합니다.

## 언제 켜나

**게임 문구를 여러 언어로 내는가?** 그렇다면 켭니다.

## 켜면 따라오는 것

| | |
|---|---|
| 규칙 | `rules/localization.md` — 키 만들기 · 시트 모양 · 내보내기 · 가져오기 · 언어 추가 |
| 도구 | 없습니다. 시트 ↔ `.po` 변환 도구는 지금 프로젝트 안에 있고, 일반화하면 이 모듈로 올립니다 |
| 프로젝트에 생기는 것 | 없습니다. 설정 파일은 UE 프로젝트의 `Config/Localization/`에 둡니다 |

없습니다.
