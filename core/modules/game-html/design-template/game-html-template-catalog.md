# game-html 서식 목록

| 서식 | 쓰는 때 | 받아 쓰는 법 |
|---|---|---|
| `game-shell.html` | HTML 게임 프로토타입을 처음 만들 때 | 프로젝트 루트에 `_prototype.html`로 복사하고 `{게임 이름}` · `{길드 이름}` · `{game}` · `{YYYY-MM-DD}`를 채웁니다 |

`game-shell.html`에 들어 있는 것 — 규칙(`../rules/game-html.md`)의 절 번호를 주석에 달아 두었습니다.

- 화면 틀(§3): 맨 위 바(정체성 · 최종 목표까지 남은 시간 막대 · 재화) · 탭 · 본문 · 맨 아래 바(가운데 턴 넘기기)
- 상태와 그리기(§4): `S` · `UI` · `render()`, `CONFIG`, 콘텐츠 표 자리, 툴팁(`data-tip`), 확인 창 `ask`, 결정 창 `decide`(지금 → 다음 비교표)
- 턴 진행(§5-1): `endWeek()` — 순서 주석과 결산 창
- 저장(§6): 판 번호를 단 `SAVE_KEY`, `try/catch`, 불러올 때 이주 자리
- 375px 너비에서 넘치지 않는 기본 레이아웃

실시간 장면(§5-2)과 무작위 표시(§7)는 장르마다 달라 서식에 넣지 않았습니다. 필요할 때 규칙의 절을 보고 더합니다.
