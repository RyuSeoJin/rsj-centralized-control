# app-preview — 가상 화면에서 앱 플로우를 비교하는 체험 도구

화면 데이터와 프로젝트 구현을 연결해 크기별 화면 전환을 비교합니다. 선택 상태 흐름으로
조건 분기·모의 요청 결과·카드별 디버그를 제공하며 실제 서비스 정책은 포함하지 않습니다.

## 언제 켜나

앱 화면을 여러 가상 뷰포트에서 선택·추가·비교할 때 켭니다.

## 켜면 따라오는 것

| 구분 | 내용 |
|---|---|
| 규칙 | rules/runtime.md — 입력·분리·표시·검증 경계 |
| 실행기 | runtime/app-preview.js — 디바이스 카드와 화면 전환 |
| 검사 | check.py · tests/runtime.cjs — 독립 실행과 브라우저 동작 검사 |
| 프로젝트에 생기는 폴더 | 없습니다. 기존 docs/·prototype/에서 데이터를 연결합니다 |
| 프로젝트가 정하는 값 | 화면·전환·프리셋·정책·토큰·에셋 |

## 전제 모듈

없습니다. 문서 조립 도구는 선택할 수 있으며 실행기는 별도 라이브러리 없이 동작합니다.
