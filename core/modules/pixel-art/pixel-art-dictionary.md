# pixel-art-dictionary — pixel-art 모듈의 용어

정의는 새로 쓰지 않고 한 줄 요약과 정의가 사는 자리만 적습니다.

| 용어 | 한 줄 요약 | 정의가 사는 자리 |
|---|---|---|
| 등신 | 키가 머리 길이의 몇 배인가 | `rules/pixel-style.md` §1 |
| 머리 단위 (H) | 정수리에서 턱까지의 길이. 기준선을 이 배수로 잽니다 | `rules/pixel-style.md` §2-1 |
| 치비 | 2~3등신 작은 캐릭터. 등신대와 규칙이 다릅니다 | `rules/pixel-style.md` §1 |
| 기준선 (anchors) | 모든 캐릭터가 공유하는 눈 · 턱 · 어깨 · 발바닥 등의 y 좌표 | `rules/pixel-style.md` §2 |
| 마스터 팔레트 | 모든 캐릭터가 함께 쓰는 번호 고정 팔레트 | `rules/pixel-style.md` §3-1 |
| 램프 | 한 재질의 밝은 색부터 어두운 색까지의 단계 | `rules/pixel-style.md` §3-2 |
| 색조 이동 | 밝을수록 따뜻하게, 어두울수록 차갑게 색조를 옮기는 것 | `rules/pixel-style.md` §3-2 |
| 셀아웃 | 외곽선을 닿는 재질의 어두운 단계로 칠하는 방식 | `rules/pixel-style.md` §4 |
| 뭉침 | 외곽선 색 2×2 덩어리. 선이 두꺼워 보입니다 | `rules/pixel-style.md` §4 |
| 접촉 그림자 | 위 파츠 바로 아래 1px을 한 단계 어둡게 하는 것 | `rules/pixel-style.md` §5 |
| 외톨이 픽셀 | 여덟 이웃과 색이 모두 다른 점 | `rules/pixel-style.md` §7-1 |
| 라인업 시트 | 캐릭터들을 기준선과 함께 나란히 놓은 검수용 그림 | `rules/pixel-style.md` §7 |
| 사양 파일 | 프로젝트의 캔버스 · 기준선 · 팔레트 · 슬롯 · 뼈대 값을 담은 JSON | `rules/pixel-pipeline.md` §0 |
| 슬롯 | 파츠 하나가 들어가는 자리. 이름과 앞뒤 순서가 고정됩니다 | `rules/pixel-rig.md` §2 |
| 스킨 | 같은 슬롯들에 끼우는 캐릭터별 그림 묶음 | `rules/pixel-rig.md` |
| 기본 자세 | 모든 캐릭터가 같은 뼈대를 쓰기 위해 공유하는 자세 | `rules/pixel-rig.md` §4 |
| 포즈 일러스트 | 규약 밖에서 따로 그리는 특정 포즈 그림. 파츠로 나누지 않습니다 | `rules/pixel-rig.md` §4 |
| 캐릭터 상자 | 몸 · 머리 · 머리카락이 들어가는 고정 크기 네모. 소품은 이 밖으로 덧댑니다 | `rules/pixel-style.md` §9-1 |
| 소품 | 캐릭터가 들거나 몸에 덧대는 무기 · 지팡이 · 모자 · 등짐. 월드에 놓는 것은 오브젝트입니다 | `rules/pixel-style.md` §9-2 |
| 레퍼런스 세트 | 스타일 기준 그림 묶음에 붙인 이름. 측정값과 특징을 `reference/{이름}.md`에 둡니다 | `rules/pixel-style.md` §10 |
| 필드 스프라이트 · 초상화 | 게임 안을 움직이는 작은 그림(치비) · 정보 화면의 큰 그림(등신대) — 용도별 사양 | `rules/pixel-style.md` §1 · §9 |
| 기준 방향 | 캐릭터를 그리는 한 방향. 반대쪽은 좌우 반전 | `rules/pixel-anim.md` §2 |
| 동작 태그 | 동작 하나에 해당하는 Aseprite 태그(`idle` · `walk` …) | `rules/pixel-anim.md` §3 |
| 공통 몸체 | 모든 캐릭터가 함께 쓰는 민무늬 몸. 동작 프레임은 여기에만 그립니다 | `rules/pixel-anim.md` §4-1 |
| 앵커 · 이동량 | 파츠가 따라 움직이는 기준점과, 프레임마다 그 점이 기본 자세에서 움직인 도트 수 | `rules/pixel-anim.md` §4-2 |
| 파츠 | 캐릭터마다 다른 머리카락 · 옷 · 소품. 기본 자세 한 장으로 그립니다 | `rules/pixel-anim.md` §4-3 |
| 이중 외곽선 | 바깥 외곽선 안쪽에 외곽선 색이 한 칸 더 붙어 2도트 두께가 된 자리 | `rules/pixel-style.md` §4-1 |
| 계단 (jaggies) | 대각선 · 곡선을 가로 · 세로 칸 무리로 나타낸 것. 길이가 고르게 변해야 매끄럽습니다 | `rules/pixel-style.md` §4-2 |
| 베개 셰이딩 | 광원과 상관없이 테두리를 둘러 어둡게 한 셰이딩. 납작해 보입니다 | `rules/pixel-style.md` §5-2 |
| 밴딩 | 램프 단계가 같은 폭의 띠로 나란히 늘어서 줄무늬로 읽히는 것 | `rules/pixel-style.md` §5-3 |
| 실루엣 시험 · 명도 시험 | 한 색으로 채운 그림 · 회색조 그림으로 읽힘을 보는 사람 검수 | `rules/pixel-style.md` §7-2 · §7-3 |
| 기준 해상도 | 그림 1도트가 화면 1칸이 되는 가상의 화면 크기. 실제 화면에는 정수배로 올립니다 | `rules/pixel-render.md` §1 |
| 믹셀 | 크기가 다른 도트가 한 화면에 섞인 상태 | `rules/pixel-render.md` §1 |
| 정수배 확대 · 레터박스 · expand | 정수 배율로만 키우고 남는 자리를 띠로 두거나(letterbox) 월드를 더 보여 주는(expand) 방식 | `rules/pixel-render.md` §2 |
| 쉬머링 | 소수배 · 소수 좌표 때문에 도트 줄이 물결처럼 흔들려 보이는 것 | `rules/pixel-render.md` §2-1 |
| 번짐 · 이음새 | 아틀라스에서 옆 그림 색이 묻어 나오는 것과, 타일 사이에 생기는 가는 선 | `rules/pixel-render.md` §3-1 |
| 스냅 | 소수 좌표를 그리기 직전에 정수 칸으로 맞추는 것 | `rules/pixel-render.md` §4 |
| 서브픽셀 떨림 | 위치가 정수 칸으로 잘리는 시점이 물체 · 프레임마다 달라 생기는 1칸 흔들림 | `rules/pixel-render.md` §5 |
| 데드존 · 감쇠 · 앞서 보기 | 카메라가 움직이지 않는 가운데 구역, 목표를 늦게 따라잡는 정도, 진행 방향을 미리 비추는 것 | `rules/pixel-render.md` §6 |
| 패럴랙스 | 먼 배경 층을 카메라보다 느리게 움직여 깊이를 내는 기법 | `rules/pixel-render.md` §8 |
| 고정 시간 갱신 · 보간 | 일정 간격의 논리 갱신과, 화면 프레임마다 직전 두 상태를 섞어 그리는 것 | `rules/pixel-render.md` §9 |
| 홀드 | 같은 그림을 몇 갱신 더 붙잡아 두는 것 | `rules/pixel-motion.md` §2 |
| 예비 동작 · 지나침 · 따라오는 동작 | 움직이기 전 반대로 움츠림, 목표를 넘었다 돌아옴, 부속 파츠가 늦게 멈춤 | `rules/pixel-motion.md` §3 |
| 스미어 프레임 | 빠른 움직임의 경로를 늘어진 모양으로 그린 한 프레임 | `rules/pixel-motion.md` §4 |
| 서브픽셀 애니메이션 | 테두리 색을 램프 중간 단계로 바꿔 1도트보다 작은 움직임처럼 보이게 하는 기법 | `rules/pixel-motion.md` §5 |
| 발 미끄러짐 | 디딘 발이 이동 속도와 맞지 않아 땅 위를 미끄러져 보이는 것 | `rules/pixel-motion.md` §7-2 |
| 히트 스톱 | 맞는 순간 두 물체를 몇 갱신 멈추는 연출 | `rules/pixel-motion.md` §8-1 |
| 타일셋 시트 | 타일을 한 장의 PNG에 격자로 모은 그림. 칸 번호는 옮기지 않습니다 | `rules/pixel-tile.md` §12 |

| 변형 타일 | 가장자리는 기본 타일과 같고 안쪽만 다른, 번갈아 까는 타일 | `rules/pixel-tile.md` §6-2 |
| 메타타일 | 타일 여러 장을 한 덩어리로 묶은 큰 그림(2×2 · 3×3) | `rules/pixel-tile.md` §2-2 |
| 늘림 테두리 (extrude) | 타일 가장자리 픽셀을 바깥으로 복사해 두른 띠. 타일 사이 번짐을 막습니다 | `rules/pixel-tile.md` §12 |
| 가독성 계층 | 먼저 읽혀야 하는 순서대로 채도 · 대비 · 외곽선을 강하게 쓰는 규칙 | `rules/pixel-tile.md` §4 |
| 공유 램프 · 배경 램프 | 캐릭터 사양에서 그대로 가져온 램프와, 같은 색조로 채도 · 대비를 낮춰 만든 `BG_` 램프 | `rules/pixel-tile.md` §3-2 |
| 지형 전이 | 두 지형이 만나는 경계 타일. 덮는 쪽의 오토타일 묶음으로 그립니다 | `rules/pixel-tile.md` §8 |

| 오브젝트 | 상자 · 문 · 나무 · 떨어진 아이템처럼 월드에 놓이는 그림. 캐릭터가 드는 것은 소품입니다 | `rules/pixel-fx.md` §5 |
