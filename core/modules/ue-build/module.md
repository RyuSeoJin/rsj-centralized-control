# ue-build — UE C++ 프로젝트를 명령으로 빌드하고 게임 창을 직접 조작해 점검합니다

에디터를 손으로 열지 않고 명령으로 빌드 · 실행하고, 떠 있는 게임 창을 스크린샷과 입력으로 점검할
때의 절차와 함정을 정합니다. 실제로 겪은 문제(Live Coding 잠금 · DPI 가상화 · 렌더러별 창 투명
동작)를 규칙으로 남긴 모듈입니다.

## 언제 켜나

**UE C++ 프로젝트를 이 저장소에서 빌드하고 실행 점검하는가?** 그렇다면 켭니다.

## 켜면 따라오는 것

| | |
|---|---|
| 규칙 | `rules/ue-build-test.md` — 빌드 · 실행 · 창 조작 점검 · 결과 기록 · 알려진 함정 |
| 도구 | 없습니다. 점검 도구는 컴퓨터마다 경로가 달라 프로젝트나 작업 폴더에 둡니다 |
| 프로젝트에 생기는 것 | 없습니다 |

## 전제 모듈

없습니다.

| 상황 | 읽는 파일 | 멈추는 자리 |
|---|---|---|
