# ue-umg — UMG 화면을 위젯 블루프린트 대신 C++ 코드로 만들 때의 함정을 피합니다

UMG 위젯을 편집기에서 배치하지 않고 C++ 코드로 만들고 갱신할 때의 규칙입니다. 다시 그리기 · 글자
넘침과 말줄임 · 자리 재기 · 입력칸 · 엔진 위젯의 한계 · 월드에 붙는 UI와 HUD의 겹침을 다룹니다.
실제로 겪은 문제(값 하나에 창 전체를 다시 만들어 끌기가 끊김 · 말줄임이 안 그려져 옆 글자 위로 넘침 ·
숨긴 위젯의 자리가 0이라 엉뚱한 곳에 펼쳐짐 등)를 엔진 동작 근거와 함께 규칙으로 남긴 모듈입니다.

## 언제 켜나

**UI를 위젯 블루프린트가 아니라 C++ 코드로 만드는가?** 그렇다면 켭니다. 위젯 블루프린트 편집기로
화면을 짜고 C++는 로직만 맡는 프로젝트라면 켜지 않습니다.

## 켜면 따라오는 것

| | |
|---|---|
| 규칙 | `rules/ue-umg-cpp.md` — 다시 그리기 · 글자 넘침과 말줄임 · 자리 재기 · 입력칸 · 엔진 위젯의 한계 · 월드 UI와 HUD 겹침 · UI 크기 규칙 검사 |
| 도구 | 없습니다. UI 크기 규칙 검사 도구는 규칙 값이 프로젝트마다 달라 프로젝트에 둡니다 |
| 프로젝트에 생기는 것 | 없습니다 |
| 프로젝트가 정하는 값 | UI 크기 규칙(틀 · 그림 칸의 단위) · 확인할 UI 배율 · 글자 폭을 따로 볼 긴 언어 목록 |

없습니다.
