# llm — 출력을 생성하는 기능을 무엇으로 검증하는가

같은 입력에도 출력이 매번 달라지는 기능이 있으면, 한 번 실행해 맞는지 보는 방식으로는
판정할 수 없습니다. 이 모듈은 그런 출력의 **검증 대상**을 정합니다 — 확률적으로 셀 것,
사람이 채점할 것, 단 1건도 나오면 안 되는 것.

## 언제 켜나

**같은 입력에 출력이 매번 달라지는 기능이 있는가?**

챗·요약·추천·생성처럼 모델이 응답을 만드는 기능이 있으면 켭니다. 출력이 항상 같은
서비스라면 켜지 않습니다 — `tc` 모듈의 결정적 유형만으로 충분합니다.

## 켜면 따라오는 것

| | |
|---|---|
| 규칙 | `llm-verification` — 확률적·루브릭 대상 목록, 루브릭 점수 서술, 금칙(안전·격리), 우회 변형 축 |
| 도구 | 없습니다 |
| 프로젝트에 생기는 것 | 없습니다 |

## 전제 모듈

`tc` — 검증유형 4종의 축과 판정 방식 위에서 돕니다.
