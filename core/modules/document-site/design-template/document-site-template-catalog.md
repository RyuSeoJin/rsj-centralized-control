# document-site-template-catalog — 공통 HTML 문서 서식

<!-- CHANGELOG · v1.0 · 2026-10-12: 범용 서식 소유를 공통 문서 모듈로 이전 -->

고르는 법과 기존 템플릿 사용 · 마스터 갱신 · 신규 템플릿 제작은 `../../../base/design-template/template-catalog.md`를 따릅니다.
표현 마스터는 `../design-guide/design-guide-master.css`입니다.

| 파일 | 용도 | 섹션과 순서의 이유 | 버전 |
|---|---|---|---|
| `04-standard.html` | 근거 · 정책 · 승인 · 적용을 설명하는 범용 기준서 | 목적 → 범위 → 근거 → 기준 → 적용 → 미결. 근거를 읽고 적용 조건을 이해합니다 | v1.0 |
| `support-environment-guide.md` | 기준서에 지원 환경 내용을 채우는 작성 안내 | 서식의 구조를 유지하며 환경 조사와 승인 정보를 구체화합니다 | 기존 안내 유지 |

기존 서식 번호는 이동해도 바꾸지 않습니다. QA 분석과 테스트 관계 서식은 이 카탈로그에 복제하지
않습니다. 템플릿은 최신 마스터를 참조하고 산출물은 생성 당시 마스터를 담습니다.
