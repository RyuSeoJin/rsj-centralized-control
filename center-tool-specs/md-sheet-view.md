## 1. 판단 — 지금은 모듈로 만들지 않습니다

받아 가는 저장소의 한 프로젝트가 Markdown 기획 정본을 스프레드시트 탭으로 내보내 보기용으로 쓰고
있습니다. 다른 프로젝트에도 쓸 만한 발상이지만, 지금 근거로는 모듈의 모양(`feature-request.md`
「모듈의 모양」)을 채우기 어렵습니다.

| 판별 | 상태 | 그래서 |
|---|---|---|
| 프로젝트 이름을 지워도 성립하는가 | 아래 2장의 원칙은 성립합니다 | 발상은 중앙 후보입니다 |
| 실제로 돌려 본 부분 | md → xlsx 내보내기 한 방향뿐입니다. 시트 → md 되읽기(2단계)는 계획만 있고 한 번도 돌지 않았습니다 | 되읽기 열쇠 형식은 아직 추측입니다(`feature-request.md` 「겪은 것을 중앙에 되돌리기」 — 겪지 않은 것은 두껍게 쓰지 않습니다) |
| 쓰는 곳 | 한 프로젝트 · 한 문서 종류 | 공통 부분과 그 프로젝트의 사정을 아직 가를 수 없습니다 |
| 규칙의 대부분 | 탭 구성 · 칸 크기 · 글자 크기 · 색 · 병합 · 열 위치 같은 시트 디자인 값 | 중앙에 올리지 않을 값입니다 |
| 도구 | 프로젝트 스크립트가 그 프로젝트의 문서 장 구성에 맞춰 짜여 있습니다 | 일반화하려면 다시 짜야 합니다 |

**올리는 조건** — 두 번째 프로젝트가 같은 보기본을 원하거나, 첫 프로젝트가 시트를 정본으로 바꾸는
2단계를 실제로 돌려 되읽기를 확인했을 때 `feature-request.md` 「프로젝트에서 자란 것을 모듈로
올리기」로 모듈을 만듭니다. 이름 후보는 `md-sheet-view`입니다.

## 2. 일반화한 규칙 후보

모듈이 생기면 `rules/`에 옮길 문장입니다.

1. **보기본은 정본이 아닙니다.** md가 정본인 동안 시트는 md에서 생성하는 사본이며, 시트에 「현재 정본
   개정을 반영함」을 표시하려면 생성에 쓴 md의 개정을 함께 적습니다. md의 장 구성이 바뀌었는데 변환기가
   아직 대응하지 않았으면 시트를 다시 만들지 않고, 옛 시트가 새 개정을 반영한 것처럼 표시하지 않습니다.
2. **시트 편집은 코멘트로만 받습니다.** 생성 탭은 「경고 후 편집」으로 보호합니다. 셀을 고치면 다음
   생성 때 덮어쓰이므로, 고칠 내용은 코멘트로 남기고 md에 반영합니다.
3. **되읽기 열쇠를 남깁니다.** 내용 오른쪽 숨긴 열에 행마다 그 행이 무엇인지(제목 · 문단 · 표 머리와 열
   위치 · 표 행 · 그림)를 적습니다. 나중에 시트를 정본으로 바꿀 때 시트 → md 역변환의 근거입니다.
   사람이 고치거나 지우지 않습니다.
4. **파일 한 장으로 가져옵니다.** 셀 수천 개를 연결 도구로 하나씩 보내면 요청이 수 MB가 되고 서식 ·
   병합 · 그림이 빠집니다. 서식 · 병합 칸 · 그림까지 담은 xlsx 한 장을 만들어 시트의 가져오기로 올리고,
   가져오기가 못 옮기는 설정(칸 크기 · 숨긴 열 · 조건부 서식 · 보호)만 연결 도구로 맞춥니다.
5. **내보낸 파일 이름에 만든 시각을 붙입니다.** 가져오기 창에서 최신 파일을 가리기 위해서입니다.
6. **정본 위치를 바꾸는 일은 별도 승인입니다.** 시트를 정본으로 바꾸는 시점에 규칙 · 구조 설정 · 등록대장을
   함께 고치고 승인을 받습니다(`canonical-source.md` — 공유본 편집과 정본 이전의 구분).

## 3. 도구 명세 초안 (모듈을 만들 때)

| 항목 | 초안 |
|---|---|
| 내보내기 | `export_sheet.py {md…} -o {xlsx}` — 장 · 절 · 문단 · 표 · 그림을 지정한 배치 규칙으로 탭에 놓고, 되읽기 열쇠 열을 씁니다. 배치 규칙(열 위치 · 크기 · 색)은 프로젝트 설정 파일 |
| 되읽기 | `import_sheet.py {xlsx} -o {md 폴더}` — 열쇠 열만 보고 md를 다시 씁니다. 첫 판은 「내보낸 직후 되읽으면 원래 md와 바이트가 같다」를 통과해야 합니다 |
| 점검 | 시험 md(장 둘 · 표 하나 · 그림 하나)를 내보내고 되읽어 바이트가 같은지 봅니다. 이 왕복 시험이 되읽기 열쇠 형식의 실제 근거가 됩니다 |
| 전제 | 표 · 그림을 시트에 놓는 라이브러리(openpyxl). tc 모듈의 xlsx 서식 지침과 겹치는 부분은 그쪽을 참조합니다 |
